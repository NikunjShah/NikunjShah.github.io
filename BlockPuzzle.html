Short description

Fill the grid with blocks! Think smart, rotate, and place to win.

Long description

A fun and addictive block puzzle game where your goal is simple — fill the grid using the available blocks!

At the bottom of the screen, you’ll find a set of unique blocks waiting to be placed. Tap a block to select it, tap again to rotate, and drag it onto the grid. If the block glows green, it fits perfectly — if it turns red, you’ll need to rethink your move!

Keep placing blocks to fill the board completely. The game ends when no more blocks can be placed or the grid is fully filled — how far can you go?

Features:

  • Simple, relaxing, and brain-teasing gameplay
  • Intuitive tap, rotate, and drag controls
  • Smart placement hints (green/red glow)
  • Minimal, clean, and colorful design
  • Satisfying sound effects and animations
  • Play anytime — no internet required
